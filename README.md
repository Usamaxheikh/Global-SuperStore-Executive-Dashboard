# Global SuperStore Executive Dashboard 📊

An interactive **Global SuperStore Executive Dashboard** built using **Tableau** to analyze sales, profitability, customers, products, regions, and discount performance.

##  Live Dashboard

🔗 [View Interactive Dashboard on Tableau Public](https://public.tableau.com/app/profile/muhammad.usama3624/viz/Global_SuperStore_Executive_Dashboard/Dashboard2)

## Project Overview

This project analyzes the Global SuperStore dataset and presents key business insights through an interactive Tableau dashboard.

The dashboard helps understand:

- Overall sales performance
- Profit and profit margin
- Monthly sales trends
- Category-wise sales and profit
- Regional sales and profit
- Top-performing products
- Loss-making products
- Relationship between discount and profit

##  Key Insights

- Technology generates the highest sales among the three major categories.
- Technology also contributes the highest profit.
- Sales show an overall increasing trend from 2011 to 2014.
- Some products generate significant negative profit.
- Higher discounts generally show a negative relationship with profitability.
